# U55 隐私友好社媒配文：旅行后分享练习

这套练习教零基础用户根据一张虚构海岸照片写出短、中、长三版社媒文案，并在发布前检查位置、时间、同行者与家庭信息。照片由图像生成工具原创生成，不对应真实地点、人物或行程；所有姓名、地点和事件均为虚构。

## 目录

- `assets/fictional_coast_sample.png`：虚构的雨后海岸栈道示例照片，无人物和地标。
- `materials/`：原始请求、当前隐私边界卡、旧版、重复件、照片便签及不可直接使用的错误草稿。
- `tutorial/隐私友好社媒配文实操教程.md`：五步实操，逐步产出照片观察、隐私边界、三版文案与发布前检查。
- `reference/参考答案与陷阱核验.md`：逐项核验素材陷阱、参考文案和发布检查记录。
- `templates/社媒配文提示词模板.md`：可换成自己场景的提示词。
- `results/三种长度参考配文.md`：本例的最终成果与长度口径。

## 示例背景

虚构练习者“小禾”旅行结束后整理相册，想发一条自然、轻松、不像广告的回顾文案。当前边界卡要求延后发布，不写精确地点和时间，不暴露同行者身份、住处或家中无人等信息。照片仅能支持“雨后木栈道、海面、远处帆船、日落”等可见描述，不能据此推断地点、日期、路线或人物身份。

## 使用说明

所有输入均为练习用虚构材料。不要把真实照片、实时行程、精确位置、儿童或他人身份信息直接交给 AI；使用真实照片前先取得必要授权并确认发布边界。平台字数上限没有提供，因此示例长度只是练习档位，不代表任何平台的硬性限制。
